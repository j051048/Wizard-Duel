# 🔮 Wizard Duel: 游戏体验与系统深度改进战略 (2026-05-07)

> **目标**: 将 Wizard Duel 从一个基础的卡牌对战原型，进化为一个具有商业化潜力、深度策略性和极佳用户体验的成熟产品。

---

## 📋 核心改进方向概览

1. **数值平衡 (Balance 2.0)**: 解决目前高费牌过于强大、前期选择匮乏的问题。
2. **系统深度 (System Depth)**: 引入元素连击、随从关键词、英雄技能树。
3. **视觉与音效 (Juice & Feedback)**: 提升打击感、动态卡牌效果、全局音效管理器。
4. **长线增长 (Progression)**: 排位赛系统、每日任务、开包系统、卡牌收集册。
5. **稳定性 (Stability)**: 后端结算校验、反作弊系统、离线断线重连。

---

## 🛠️ Phase 1: 系统稳健性与数值平衡 (Immediate)

### 1.1 后端结算加固 (RPC)

- [x] **实现 `settle_battle_secure`**: 所有金币和积分结算必须在 PostgreSQL RPC 端完成。
- [x] **防止负分**: 确保 `rank_score` 最小值为 0。
- [x] **连胜奖励**: 引入连胜加成系数（基于 `win_streak`）。

### 1.2 数值平衡调整 (Balance v2.0)

- **低费卡牌填充**: 增加 0-2 费的功能性卡牌（如：0费 1伤的 `fire_embers`, 1费 1冻结的 `ice_bite`）。
- **高费卡削弱**: 适当降低 Ultimate 卡牌的即时伤害，增加其“施法准备”感（例如伤害分段触发）。
- **护甲价值重估**: 提高 `rock` 元素卡牌的护甲收益，使其在面对爆发时有更强的生存力。

### 1.3 类型系统修复

- [x] **SpellType 重构**: 将 `SpellType` 从联合类型改为 `string`，支持动态扩展。
- [x] **稀有度校验**: 清理所有 `'uncommon'` 的非法定义，统一为 `common`, `rare`, `mythic`, `legendary`。

## 🐉 Phase 2: 战斗系统深度化 (Development)

### 2.1 随从系统 (Minions v2.0)

目前的随从只是简单的属性点，需要引入类似《炉石传说》的关键词系统：

- **Taunt (嘲讽)**: 必须先攻击具有嘲讽的随从。
- **Divine Shield (圣盾)**: 免疫下一次受到的伤害。
- **Rush (突袭)**: 召唤回合即可攻击随从，但不能攻击英雄。
- **Deathrattle (亡语)**: 随从死亡时触发的效果（召唤、伤害、治疗）。

### 2.2 元素连击系统 (Combo Synergy)

鼓励玩家在同一回合或连续回合使用特定元素：

- **Steam (蒸气)**: `fire` -> `ice` (或反之)，造成额外 2 点无视防御的伤害。
- **Overload (超载)**: 连续使用 `thunder` 牌，下一回合可获得额外法力，但本回合后续费用增加。
- **Growth (生长)**: `vine` -> `rock`，永久增加本回合随从的攻击力。

## 🎨 Phase 3: 表现力与用户反馈 (UI/UX)

### 3.1 动态卡牌效果 (Card VFX)

- [ ] **发光边缘**: 根据稀有度显示不同颜色的动态边缘（Legendary 为流光金）。
- [ ] **卡面视画**: 鼠标悬停时卡牌有微小的 3D 旋转效果。
- [ ] **元素背景**: 卡面背景根据元素类型显示动态粒子（火焰、雪花、落叶）。

### 3.2 深度音效反馈 (Audio Manager)

- [x] **全局音效注册**: 建立 `sfxRegistry.ts`。
- [x] **路径规范化**: 统一使用 `/audio/` 路径，移除 `/sounds/`。
- [ ] **打击音效**: 根据伤害大小触发不同权重的命中音效。
- [ ] **BGM 切换**: 根据对局阶段（平稳/决战）平滑切换背景音乐。

## 📈 Phase 4: 长线系统与商业化 (Growth)

### 4.1 段位赛系统 (Ranked Season)

基于 `rank_score` 划分 9 个大段位：

- **Iron** (0 - 999): 萌新保护，失败不扣分。
- **Silver** (1000 - 2499): 扣分减半。
- **Gold** (2500 - 4499): 标准规则开始。
- **Platinum** (4500 - 6999)
- **Diamond** (7000 - 9999)
- **Epic** (10000 - 13999)
- **Master** (14000 - 18999)
- **Mythic** (19000 - 24999)
- **Legend** (25000+): 全服排名。

### 4.2 每日任务与开包 (Quests & Packs)

- **每日任务**: 例如“使用 10 张火系卡牌”、“获得 3 场胜利”。
- **卡牌包**: 分为基础包、元素包。
- **收集册**: 展示已获得和未获得的卡牌，增加玩家收集欲望。

## 🚀 详细功能模块设计

### 1️⃣ 社交与多人交互系统

#### 🤝 好友与公会

- **实时好友状态**: 在线、战斗中、空闲。
- **公会聊天**: 频道式即时通讯。
- **对局分享**: 玩家可以将精彩对局的 Replay 分享到公会频道。
- **公会宝箱**: 根据成员周胜场总数解锁不同级别的宝箱。

#### 🎁 社交互动

- 赠送卡包/金币
- 好友对战（不消耗入场费）
- 表情/语音快捷语

---

### 2️⃣ 新手体验优化 - 降低流失率

#### 🎓 教学系统重构

**当前问题**: 教学可能过于简单或跳过关键机制

**改进方案**:

- **分阶段教学**:
  - 第 1 关：基础操作（出牌、攻击）
  - 第 2 关：法力管理
  - 第 3 关：元素克制
  - 第 4 关：特殊机制（嘲讽、冲锋等）
  - 第 5 关：牌组构建基础

- **互动式教学**:
  - 强制引导（高亮可操作区域）
  - 即时反馈（做对了给予鼓励）
  - 可跳过（老玩家）

- **新手任务链**:
  - 完成教学 → 奖励新手卡包
  - 赢得首场对战 → 奖励金币
  - 构建首个牌组 → 奖励稀有卡
  - 达到等级 5 → 解锁排位赛

**技术实现**:

```typescript
interface TutorialStep {
  id: string;
  title: string;
  description: string;
  highlightElement?: string;
  requiredAction: 'play_card' | 'attack' | 'end_turn' | 'build_deck';
  reward?: Reward;
  skippable: boolean;
}
```

#### 🎁 新手福利

- **登录奖励**:
  - 前 7 天每日登录送卡包
  - 第 7 天送传说卡
- **新手保护期**:
  - 前 10 场对战匹配同等级玩家
  - AI 难度自适应
- **快速升级**:
  - 前 10 级经验需求减半
  - 每级奖励更丰厚

---

### 3️⃣ 竞技平衡与深度

#### ⚖️ 平衡性调整

**当前问题**: 元素克制可能导致 "剪刀石头布" 问题

**解决方案**:

- **克制机制优化**:
  - 克制伤害从 2x 降低到 1.5x（减少极端情况）
  - 引入 "中立元素" 卡牌（不受克制影响）
  - 添加 "反克制" 机制（特定卡牌可以反制克制）
- **卡牌平衡**:
  - 定期数据分析（胜率、使用率）
  - 每月平衡性补丁
  - 社区反馈机制
- **元游戏多样性**:
  - 确保至少 5 种主流牌组类型
  - 快攻、中速、控制、组合技都有生存空间

#### 🎯 竞技模式深化

- **天梯系统**:
  - 青铜 → 白银 → 黄金 → 铂金 → 钻石 → 大师
  - 每个段位 5 个小段
  - 赛季奖励（卡背、称号）
- **锦标赛模式**:
  - 每周末举办
  - 瑞士轮制或单败淘汰
  - 丰厚奖励
- **排行榜细分**:
  - 全球榜、地区榜、好友榜、职业榜

---

### 4️⃣ 商业化与变现

#### 💰 变现路径优化

**多元化变现**:

1. **战令系统 (Battle Pass)**: $9.99/赛季，包含卡包、金币、独家卡背。
2. **外观商城**: 包含卡背、头像框、表情包、棋盘皮肤、英雄皮肤。
3. **限时优惠**: 新手礼包、节日礼包、每日特惠。
4. **广告变现**: 观看广告获得额外体力或少量金币。

#### 🎨 付费内容设计原则

- **非 Pay-to-Win**: 所有卡牌均可通过游玩获得，付费仅加速进度或购买外观。
- **价值感**: 确保付费内容物超所值。
- **尊重免费玩家**: 保持游戏核心体验对所有人开放。
