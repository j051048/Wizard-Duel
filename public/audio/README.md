# 音效资源说明

本文件夹用于存放游戏音效资源。

## 需要的音效文件列表：

### BGM (背景音乐)
- `bgm-lobby.mp3` - 大厅背景音乐 (轻松神秘的魔法氛围)
- `bgm-battle.mp3` - 战斗背景音乐 (紧张刺激的对战氛围)

### SFX (音效)
- `sfx-card-play.mp3` - 打出卡牌音效
- `sfx-spell-fire.mp3` - 火焰法术音效
- `sfx-spell-ice.mp3` - 冰霜法术音效
- `sfx-spell-thunder.mp3` - 雷电法术音效
- `sfx-spell-vine.mp3` - 藤蔓法术音效
- `sfx-spell-rock.mp3` - 岩石法术音效
- `sfx-hit.mp3` - 命中/受伤音效
- `sfx-block.mp3` - 格挡/平局音效
- `sfx-victory.mp3` - 胜利音效
- `sfx-defeat.mp3` - 失败音效

## 推荐资源

可以从以下免费音效网站获取：
- [Freesound](https://freesound.org/)
- [Mixkit](https://mixkit.co/free-sound-effects/)
- [Zapsplat](https://www.zapsplat.com/)

**注意**: 请确保使用的音效符合商业使用许可。
